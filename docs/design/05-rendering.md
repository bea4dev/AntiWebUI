# 05. レンダラ（anti-webui-wgpu）

## 入力: Scene

core はフレームごとに `Scene`（描画コマンドの列）を生成する。座標は物理 px。

```rust
enum Primitive {
    Shadow(Shadow),      // ボックスシャドウ
    Quad(Quad),          // 背景・枠線・角丸・キャレット・選択ハイライト・下線
    Glyphs(GlyphRun),    // フォント参照・サイズ・座標・色
}
```

どのプリミティブも自分のクリップ矩形を持つ（push/pop 型のクリップスタックは使わない）。

- `Quad`: 整数矩形、背景色、辺ごとの枠線幅（整数）、枠線色、4 隅の角丸半径（f32）、影（オフセット・ぼかし・色）。
- `GlyphRun`: フォントデータ（`Blob` + index）、物理フォントサイズ、正規化座標（可変フォント）、合成（太字・斜体）、色、各グリフの `(id, x, y)`。

## GPU 側

- **矩形パイプライン**: インスタンス描画。フラグメントシェーダで角丸矩形の SDF を評価し、枠線と背景を 1 パスで描く。影はガウスぼかしを近似した解析式で描く。
- **グリフパイプライン**: インスタンス描画。RGBA8 アトラス 1 枚。単色グリフはカバレッジを、カラー絵文字はプリマルチプライド色を格納し、インスタンスのフラグで区別する。
- **クリップ**: インスタンスごとにクリップ矩形を持たせ、シェーダで判定する（バッチを分けずに済む）。
- **順序**: Scene の順に、同じパイプラインが続く区間を 1 ドローコールにまとめる。
- **ブレンド**: プリマルチプライドアルファ。ブラウザと同じくガンマ空間（非 sRGB フォーマット）で合成する。

## グリフキャッシュ

- キー: `(フォント blob id, フォント index, グリフ id, 物理サイズ（1/64 px 量子化）, サブピクセル x（1/4 px）, 合成フラグ, 可変フォント座標のハッシュ)`。
- ラスタライズは swash。ソース優先順: カラーアウトライン → カラービットマップ → アウトライン。
- アトラスはシェルフパッキング。満杯になったら拡張し、それでも足りなければクリアして次フレームで再構築する。

## 表示

- サーフェス形式は `Bgra8Unorm` / `Rgba8Unorm`（非 sRGB）を優先。
- バックエンドはまず Vulkan / Metal / DX12 を試し、アダプタが無いときだけ GL に落ちる（Mesa の GL は LLVM を読み込むため重い）。環境変数 `WGPU_BACKEND` で上書きできる。
- PresentMode は `Mailbox` → `Fifo` の順で選ぶ。フレームの律速は Wayland のフレームコールバックで行う（非表示ウィンドウで WSI がブロックするのを避ける）。
- オフスクリーン描画（テクスチャ → PNG）をサポートし、テストとスクリーンショットに使う。

## デバッグ

- `ANTIWEBUI_DUMP_FRAME=out.png` を指定すると、表示したフレームと同じ Scene をオフスクリーンで描画して PNG に書き出す（画面キャプチャ無しで実バッファの内容を確認できる）。
- `anti_webui_app::headless::{render_png, render_driven_rgba}` で、合成イベントを流した後の状態をスナップショットにできる。
