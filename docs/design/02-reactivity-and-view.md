# 02. リアクティブシステムとビュー構築

## 書き味

```rust
fn counter() -> impl IntoView {
    let count = signal(0);
    div()
        .flex().flex_col().gap(8.0).p(16.0)
        .child(text(move || format!("Count: {}", count.get())))
        .child(button("+1").on_click(move |_| count.update(|c| *c += 1)))
}
```

- コンポーネント関数は **一度だけ** 実行される。
- 変化しうる箇所にはクロージャを渡す（`text(move || ...)`, `.dyn_style(move |s| ...)`）。クロージャは effect として登録され、依存する signal が変わったときだけ再実行されて、対応するノードだけが更新される。仮想 DOM の差分計算はない。

## リアクティブ・プリミティブ

| API | 内容 |
|---|---|
| `signal(v) -> Signal<T>` | 読み書きできる値。`Copy` なハンドル |
| `memo(f) -> Memo<T>` | 派生値。`PartialEq` で変化を判定し、変わらなければ下流に伝播しない |
| `effect(f)` | 副作用。依存が変わると再実行 |
| `batch(f)` | 複数の書き込みをまとめて 1 回だけ伝播 |
| `untrack(f)` | 依存を記録せずに読む |
| `on_cleanup(f)` | 現在のオーナーが破棄・再実行されるときに呼ぶ |
| `create_root(f) -> (T, Owner)` | 新しいルートオーナー |

### 実装

- スレッドローカルなランタイム。signal / 計算ノードは `slotmap` のアリーナに置き、ハンドルは `Copy`。
- 値は `Rc<RefCell<Box<dyn Any>>>` に格納し、ランタイムの借用を解放してからユーザーのクロージャに渡す（再入可能）。
- 伝播は **Clean / Check / Dirty の 3 色アルゴリズム**（push で印を付け、pull で再計算）。グリッチ（中間状態の観測）を起こさない。
  1. signal 書き込み: 直接の購読者を Dirty、その先を Check にし、effect をキューに積む。
  2. flush: キューの effect を順に「必要なら更新」。Check のノードは上流の memo を先に更新し、本当に値が変わったときだけ Dirty に昇格する。
- 計算ノードは実行のたびに依存を張り直す（動的依存）。
- 計算ノードはオーナーでもあり、実行中に作られた signal・計算・ノード・cleanup を所有する。再実行・破棄の前に子を破棄する。

## ノードツリー

- スレッドローカルな `Tree`（`slotmap`）に保持する DOM 的なツリー。
- ノード種別: `Element`（div）、`Text`、`TextEdit`（入力欄）、`Fragment`（レイアウト上は透過、動的な子の差し替え口）。
- ノードは生成時のオーナーに cleanup を登録し、オーナー破棄時にツリーから取り除かれる。
- 取り除かれたノードがフォーカス・選択・ホバーの対象だった場合は、それらを解除する。

## ビュー構築

- `div()` などのビルダーはスタイル・ハンドラ・子を一時的に保持し、`IntoView::into_view()` の時点でノードを生成する。
- `Styled` トレイトがスタイル用ビルダーメソッド（`.w()`, `.flex()`, `.bg()` …）を提供し、`Div` と `Style`（リファインメント）の両方が実装する。これにより `.hover(|s| s.bg(color))` のように同じ書き方で状態別スタイルを書ける。
- 動的な子:
  - `dyn_view(move || ...)`: 依存が変わるたびに中身を作り直す（Fragment ノード + 子オーナー）。
  - `show(when, view)`: 条件表示。
  - `for_each(items, key, view)`: キー付きリスト。キーが同じ要素はノードを再利用し、並べ替えだけ行う。`.enter` / `.exit` で項目の出入りを動かせる（[13](13-animation.md)）。

## イベント

- ハンドラは `Rc<dyn Fn(&Event)>` としてノードに保持する。ディスパッチ時はツリーの借用を解放してから呼ぶ。
- ハンドラ呼び出しは `batch` で包む。
- バブリング: ターゲットから親へ。`event.stop_propagation()` で停止。
- 同じ種類のリスナーを複数付けると、付けた順にすべて呼ばれる。部品が使っているリスナーを、利用者の `.on_hover(...)` が消さないようにするため。
- `on_active(bool)` は押下の開始と終了を伝える。ポインタが外に出てから離したときも来る。
- `on_focus_visible(bool)` は CSS の `:focus-visible` に当たる。キーボードで移ったフォーカスだけを伝える。
