# 01. 物理整数ピクセルモデル

## 方針

スタイルの値は **論理ピクセルの `f32`** で受け取る。ただしスタイル解決とレイアウトは、**バッファサイズとスケールの両方が確定してから**行い、その時点で全ての長さを **物理ピクセルの `i32`** に変換する（XAML の `UseLayoutRounding` に近い考え方）。

```
Style（論理 px, f32, Option だらけのリファインメント）
   │ カスケード（基本 → hover/active/focus パッチ → 動的パッチ）＋ 継承
   ▼
ComputedStyle（論理 px, f32, 全フィールド確定）
   │ × Scale(n/120)、丸め
   ▼
ResolvedStyle（物理 px, i32）
   │ 自前 Flex レイアウト（整数）
   ▼
LayoutRect（物理 px, i32）
```

## 3 方式の比較（スケール 1.5、幅 33 論理px を 3 つ並べる）

| | A: float のまま | B: 辺だけスナップ（Chromium・taffy） | C: 先に整数化（採用） |
|---|---|---|---|
| 1つ目 | [0, 49.5) にじむ | [0, 50) 幅 50 | [0, 50) 幅 50 |
| 2つ目 | [49.5, 99) にじむ | [50, 99) **幅 49** | [50, 100) 幅 50 |
| 枠線 1px | 1.5px でにじむ | 辺ごとに 1 か 2 | 全辺同じ太さ |
| 合計 | 148.5 | 149 | 150（1px はみ出しうる） |

C は「同じ指定の要素は、どこに置いても同じ物理サイズ」を保証する。合計のずれは、固定サイズ要素では許容し、伸縮要素では整数分配でぴったり埋める（[03](03-layout.md)）。

## 規則

### R1. 丸め関数は 1 つ
```rust
pub fn to_physical(logical: f32, scale: Scale) -> i32 {
    (logical as f64 * scale.0 as f64 / 120.0).round() as i32
}
```
- `f64::round` は 0.5 を 0 から遠い方へ丸めるため、負値でも対称。
- スケールは `n/120` の整数 `n` で保持する（1.25 = 150, 1.5 = 180）。

### R2. 非ゼロの枠線は最低 1px
`border_px = if w > 0 { max(1, to_physical(w)) } else { 0 }`。輪郭（outline）・フォーカスリングも同じ。

### R3. ルートはバッファサイズが正
ウィンドウの論理サイズ × スケールを自前で計算せず、**実際に確保したバッファの物理サイズ**をルートの制約とする。Wayland では `buffer = round(logical × n / 120)` を採用し、`wp_viewporter.set_destination(logical)` で表示サイズを伝える。

### R4. テキストは「箱は整数、中身はサブピクセル」
- 物理フォントサイズ（`font_size × scale`、f32 のまま）でシェイピングする。
- 行の高さ・ベースラインは parley の `quantize = true` で整数化する。
- グリフの水平位置は丸めず、1/4 px 単位でサブピクセル配置する（グリフキャッシュのキーに含める）。
- テキストボックスの幅は advance 合計の `ceil`。

### R5. 整数化はジオメトリのみ
箱の位置・サイズ・枠線・パディング・マージン・gap は整数。角丸半径・影のぼかし・透明度・transform は描画時に f32 のまま扱う。

### R6. アニメーションはレイアウトに入れない
レイアウト（整数）と描画時の変形（f32）を分離する。スクロール量は物理 px の整数。

### R7. OS へ渡す座標は論理に戻す
- IME のカーソル矩形（text-input-v3）、ポップアップ位置（xdg_positioner）は論理座標。`physical / scale` で変換する。
- 入力イベントの座標は `logical × scale` で物理 f32 にしてからヒットテストする。

## スケール変更時

スケールは core 内でリアクティブな値として保持する。変化すると全ノードの `ResolvedStyle` とテキストレイアウトが無効化され、次フレームで再計算される。レイアウトキャッシュはスケールをキーに含む。
